# 그림 파일 (public/props/)

여기에 png 를 넣고 `src/rpg/ui/art/sprites.ts` 의 `SPRITES` 표에 줄을 더하면
그 물건이 도형 대신 그림으로 그려집니다. **한 장씩 켜고 끌 수 있습니다** —
표에 없거나 파일이 없으면 지금 도형으로 그대로 떨어집니다.

## 지켜야 하는 것 넷

1. **그림자를 굽지 마라.** 그림자는 코드가 그립니다 (`terrain.ts` 의 `drawProp`,
   `actors.ts` 의 `drawShadow`). 구우면 그림자가 둘이 되고 방향이 어긋납니다.
2. **빛은 왼쪽 위에서 온다** (`palette.ts` 의 `LIGHT = {x:-0.55, y:-0.84}`, 약 123°).
   좌우를 볼 때 코드가 `scale(-1,1)` 로 통째 뒤집으므로, 한쪽에만 진한
   하이라이트를 구우면 왼쪽을 볼 때 빛이 오른쪽에서 옵니다.
3. **아래 끝이 발밑이다.** 그림의 아래 끝이 그 물건이 땅에 닿는 자리입니다.
   장애물은 타일 위에서 0.72 지점입니다 (`draw.ts` 의 깊이 정렬과 같은 값).
4. **배경은 투명.** 그리고 3배로 그립니다 — 최대 확대가 2.75배(zoom 1.375 × DPR 2)라
   3배면 언제나 축소만 되어 안 뭉갭니다.

## 키 이름

| 갈래 | 키 | 없으면 |
|---|---|---|
| 장애물 | `<테마>/<종류>` — 예 `forest/tree`, `cave/rock` | `<종류>` 를 찾고, 그것도 없으면 도형 |
| 광맥 | `vein/<광맥id>` — 예 `vein/iron-shallow` | `vein` 을 찾고, 없으면 도형 |
| 바닥난 광맥 | `vein/empty` | 도형 |
| 몬스터 | `monster/<몬스터id>` — 예 `monster/wolf` | `shape/<모양>` (beast·bat·spider) 를 찾고, 없으면 도형 |

테마는 `town` · `forest` · `cave` · `river` 넷입니다.
장애물 종류 중 실제로 화면에 나오는 것은 여덟뿐입니다 —
`tree` `pine` `bush` `rock` `spire` `beam` `deadbush` `crystal`.

## 지역별 색

그림에 색이 박히므로 지역을 맞춰 뽑아야 합니다.

| 지역 | 밝은 면 / 중간 / 어두운 면 |
|---|---|
| 마을 | `#4e7440` / `#2f5233` / `#1d3722` |
| 초록 숲 | `#456e39` / `#2b4a2c` / `#19311e` |
| 광산 | `#544c60` / `#3a3442` / `#221d2a` — 보랏빛. **초록 이끼 금지** |
| 강가 | `#8a9463` / `#5e6a43` / `#39422a` — 올리브 |

마을 지붕만 붉습니다 (`#8d4f3a`).
공기색과 안개는 화면 전체에 덮이므로 그림 위에도 그대로 걸립니다.

## 없으면 조용히 사라지지 않는다

표에 적어놓고 파일이 없으면 콘솔에 **한 번** 적힙니다
(`그림을 못 찾았습니다: <키> → <경로>`). `spriteFailures()` 로도 볼 수 있습니다.
`drawImage` 에 안 받아진 이미지를 넣으면 브라우저가 예외도 로그도 없이
아무것도 안 그리기 때문에, 그것을 막으려고 둔 그물입니다 (CLAUDE.md 6장).
