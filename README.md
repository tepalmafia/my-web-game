# AGI 경주

데이터센터를 짓고 GPU와 전력을 확보해, 경쟁 연구소 세 곳보다 **먼저 AGI에 도달**하면 이기는 브라우저 게임입니다.

▶ **[플레이하기](https://tepalmafia.github.io/my-web-game/)**

한 판은 약 25분입니다. 설치할 것도, 가입할 것도 없습니다. 휴대폰에서도 됩니다.

## 어떤 게임인가

버튼을 눌러 자원을 굴리는 경영 시뮬레이션입니다. 화면에서 뛰어다니는 캐릭터는 없고, 대신 **매 순간의 선택**이 25분 뒤의 승패를 가릅니다.

- **투자를 받으면 지분이 줄어듭니다.** 일곱 번쯤 받으면 더 내줄 지분이 없습니다. 게다가 투자자는 성과를 보고 돈을 내므로, 급하다고 한 번에 몰아 받을 수 없습니다.
- **GPU는 전력이 있어야 돕니다.** 전력 계약을 잊고 GPU만 사면 산 만큼 그대로 놀립니다. 이 게임에서 가장 자주 걸리는 함정입니다.
- **GPU를 둘 자리도 필요합니다.** 자리가 차면 데이터센터를 새로 지어야 하고, 지을수록 비싸집니다.
- **안전 검증을 건너뛰면 빨라집니다.** 대신 사고가 나면 그 자리에서 패배합니다. 뒤처졌을 때 이 슬라이더를 내릴 것인가가 이 게임의 마지막 질문입니다.
- **경쟁사는 손댈 수 있는 상대입니다.** 첩보를 사서 진짜 진행도를 확인하고, 인재를 빼와 상대를 늦추고, GPU 물량을 선점해 셋 다 묶을 수 있습니다. 다만 거기 쓴 돈은 내 GPU로 돌아오지 않고, 늦춘 효과는 시간이 지나면 풀립니다.

처음에는 버튼이 두 개뿐입니다. 진행하면서 전력·데이터센터·연구원·경쟁사 상황판·안전 조절이 하나씩 열립니다.

### 후반에는 게임이 바뀝니다

진행도 45%를 넘으면 **모델이 스스로 연구를 돕기 시작합니다.** 그때부터 질문이 달라져요.

> 전반: 무엇을 살까 (돈 → 설비 → 속도)
> 후반: 그 힘을 어디에 쓸까 (**가속 ↔ 정렬**)

가속에 몰면 최대 3.5배까지 빨라지지만 **통제력**이 깎이고, 0이 되면 그 자리에서 패배합니다. 정렬에 몰면 통제력은 회복되지만 경쟁사에 뒤처집니다. 깊이 들어갈수록 균형점이 정렬 47% → 64%로 올라가서, **가속과 정렬을 동시에 가질 수 없게 됩니다.** GPU를 몇백 장 더 사는 것보다 이 저울을 몇 %p 움직이는 쪽이 훨씬 크게 작용합니다.

## 만들면서 정한 것

숫자를 만지는 사람과 코드를 만지는 사람이 서로를 방해하지 않도록 경계를 나눴습니다.

| 위치 | 역할 |
|---|---|
| `src/types.ts` | 게임에 존재하는 모든 정보의 형태. **동결** — 새 개념이 생길 때만 바뀝니다 |
| `src/balance.ts` | **조절 가능한 모든 숫자.** 난이도를 바꾸려면 이 파일만 고치면 됩니다 |
| `src/constraints/` | 한계 판정 — 가격, 수용량, 전력 부족, 승패 경계 |
| `src/state/` | 리듀서와 매 순간의 시뮬레이션, 사건, 시드 난수 |
| `src/input/` | 버튼 판정 — 지금 누를 수 있는가, 얼마인가, 왜 안 되는가 |
| `src/render/` | 화면. 게임 규칙을 스스로 판단하지 않습니다 |

계산해서 알 수 있는 값(전력 소비량, 연구 속도, 남은 시간)은 상태에 **저장하지 않고** 매번 다시 계산합니다. 저장하면 실제 값과 어긋나는 버그가 반드시 생기기 때문입니다.

난수에는 씨앗이 있어서, **같은 씨앗이면 사건 순서까지 똑같은 판이 그대로 재현**됩니다. 덕분에 봇으로 수십 판을 자동으로 돌려 밸런스를 숫자로 확인할 수 있습니다.

## 직접 돌려보기

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입검사 + 프로덕션 빌드
npm run typecheck  # 타입검사만
```

`main`에 푸시하면 GitHub Actions가 빌드해서 GitHub Pages에 자동 배포합니다.

## 난이도 조절

`src/balance.ts` 하나만 열면 됩니다. 자주 만지게 될 값들:

| 값 | 효과 |
|---|---|
| `RESEARCH.perGpuPerSecond` | 게임 전체 속도. 두 배로 하면 대략 절반 시간에 끝납니다 |
| `RIVALS[].baseSpeed` | 경쟁사가 얼마나 무서운지. 가장 빠른 랩이 사실상 제한시간입니다 |
| `FUNDING.baseAmount` | 돈이 얼마나 넉넉한지 |
| `FUNDING.roundIntervalSeconds` | 투자 라운드가 얼마나 촘촘히 열리는지 |
