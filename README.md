# 아덴의 그림자

사냥하고, 모으고, **강화하는** 옛날식 온라인 RPG. 혼자서, 브라우저에서, 설치 없이.

▶ **[플레이하기](https://tepalmafia.github.io/my-web-game/)**

땅을 누르면 걷고 몬스터를 누르면 다가가 알아서 때립니다. 레벨을 올리고, 장비를 모으고,
마법 주문서로 그 장비를 강화합니다. 마지막에는 4분마다 되살아나는 고룡이 기다립니다.

---

## 어떤 게임인가

이 게임의 중심은 레벨이 아니라 **강화**입니다.

- **+3 까지는 반드시 성공합니다.** 그 위로는 75% → 60% → 45% → 33% → 22% → 14% → 8% 로 떨어지고,
  **일반 마법 주문서로 실패하면 그 장비는 그 자리에서 부서져 사라집니다.**
  축복받은 주문서는 실패해도 +0 으로 돌아갈 뿐이라 장비가 남지만, 훨씬 비쌉니다.
- +7 짜리 무기 한 자루가 레벨 다섯보다 셉니다. 그래서 골드는 결국 전부 주문서로 갑니다.

나머지는 이 한 가지를 받치는 구조입니다.

| | |
|---|---|
| **직업 셋** | 기사(맞으면서 팬다) · 요정(멀리서 빠르게) · 마법사(유리대포). 무기 계열이 달라 서로의 장비를 쓸 수 없습니다 |
| **지역 여섯** | 마을 → 초원 → 고블린 협곡 → 버려진 광산 → 오크 요새 → 용의 둥지. 한 줄로 이어져 있고, 한 번 가본 곳은 마을에서 순간이동으로 갈 수 있습니다 |
| **필드 보스** | 사냥터마다 하나씩. 바닥에 붉은 원이 그려지면 그 자리에서 벗어나야 합니다. 죽이면 90~140초 뒤 다시 나타납니다 |
| **고룡 카르나스** | 마지막 보스. 4분마다 부활하므로 몇 번이고 다시 도전할 수 있습니다. 전설 장비는 전부 여기서 나옵니다 |
| **죽음** | 지금 레벨에서 모은 경험치의 30%와 골드의 8%를 잃고 마을에서 깨어납니다. 부활 주문서를 미리 사두면 그 절반을 되찾습니다 |
| **자동 사냥** | Space 한 번이면 알아서 잡고, 알아서 줍고, 체력이 절반 아래로 내려가면 알아서 물약을 마십니다. 다만 보스에게는 스스로 덤비지 않습니다 |

조작은 마우스 하나로 끝납니다. 1·2·3 으로 스킬, Q·W 로 물약, Space 로 자동 사냥.
휴대폰에서는 화면 아래 단추가 같은 일을 합니다. 기록은 브라우저에 저장되므로 창을 닫아도 이어서 할 수 있습니다.

## 만들면서 정한 것

숫자를 만지는 사람과 코드를 만지는 사람이 서로를 방해하지 않도록 경계를 나눴습니다.

| 위치 | 역할 |
|---|---|
| `src/rpg/types.ts` | 게임에 존재하는 모든 정보의 형태. **동결** — 새 개념이 생길 때만 바뀝니다 |
| `src/rpg/balance.ts` | **조절 가능한 모든 숫자.** 난이도를 바꾸려면 이 파일만 고치면 됩니다 |
| `src/rpg/content/` | 아이템·몬스터·지역·스킬·퀘스트 목록. 표만 있고 계산은 없습니다 |
| `src/rpg/core/` | 규칙 — 전투 계산, 이동과 지형, 전리품, 강화, 성장, 저장 |
| `src/rpg/ui/` | 화면. 게임 규칙을 스스로 판단하지 않고 `core/` 의 함수를 부르기만 합니다 |

**계산해서 알 수 있는 값은 저장하지 않습니다.** 최대 체력, 공격력, 방어력은 장비와 버프에서
매번 다시 구합니다. 한 번 저장해두면 장비를 바꿨을 때 실제 값과 어긋나는 버그가 반드시 생깁니다.

**지형도 저장하지 않습니다.** 지역마다 정해진 씨앗으로 그때그때 만들어내며, 같은 씨앗이면 언제나
같은 지도가 나옵니다. 만든 뒤에는 입구에서 모든 문까지 실제로 걸어갈 수 있는지 확인하고,
닿지 않는 구덩이는 아예 막아버립니다 — 거기 태어난 몬스터는 영영 잡을 수 없기 때문입니다.

## 어떻게 확인하는가

화면을 눌러보지 않고도 규칙이 맞는지 알 수 있어야 합니다. 그래서 검사가 두 겹입니다.

### 1. 테스트 — `npm test` (190개, 2초)

```bash
npm test          # 한 번 돌리기
npm run test:watch # 고칠 때마다 자동으로
npm run check     # 타입검사까지 함께
```

| 파일 | 무엇을 지키는가 |
|---|---|
| `content.test.ts` | 표의 오타. 없는 아이템을 떨구거나, 없는 지역으로 이어지는 문이 없는지 |
| `enhance.test.ts` | 확률표와 실제 결과가 맞는지. 축복 주문서가 정말 장비를 남기는지 (1000번 실패시켜 확인) |
| `world.test.ts` | 만들어진 지도에 **걸어서 닿지 않는 칸이 없는지**. 길찾기가 벽을 뚫지 않는지 |
| `engine.test.ts` | 3분을 실제로 돌려보고 벽에 끼거나 좌표가 깨지지 않는지 |
| `combat.test.ts` · `stats.test.ts` | 피해·방어·강화 효과가 숫자대로 나오는지 |
| `progression.test.ts` · `quests.test.ts` | 레벨업, 죽음의 대가, 의뢰 완료와 보상 |
| `inventory.test.ts` · `commands.test.ts` | 가방·상점(무한 돈벌이가 없는지)·스킬·순간이동 |
| `save.test.ts` | 저장한 게 그대로 돌아오는지. 기록이 깨져 있어도 게임이 멈추지 않는지 |

풀 리퀘스트를 올리면 GitHub Actions 가 이 셋(타입검사·테스트·빌드)을 자동으로 돌립니다.

> 이 테스트로 실제로 잡은 버그: **자동 사냥이 바위 뒤 몬스터를 향해 직진하다 150초 동안 멈춰 있던 문제.**
> 눈으로 보던 화면에서는 입구 근처가 트여 있어 드러나지 않았습니다. 지금은 길찾기가 들어가 있습니다.

### 2. 봇 — 몇 시간 치를 몇 초에

난수에 씨앗이 있어서 같은 판을 그대로 재현할 수 있습니다. 밸런스는 눈이 아니라 이걸로 맞췄습니다.

```bash
npx esbuild tools/sim.ts --bundle --format=esm --platform=node --outfile=/tmp/sim.mjs
node /tmp/sim.mjs knight 3            # 기사로 3시간 자동 사냥
node /tmp/sim.mjs wizard 0 boss       # 만렙 전설 장비로 고룡전
node /tmp/sim.mjs wizard 0 boss-early # 희귀 +3 장비로 고룡전 (아직 무리입니다)
```

## 난이도 조절

`src/rpg/balance.ts` 하나만 열면 됩니다. 자주 만지게 될 값들:

| 값 | 효과 |
|---|---|
| `ENHANCE_CHANCE` | 강화가 얼마나 잔인한가. 이 게임의 성격을 정하는 표입니다 |
| `expToNextLevel()` | 레벨업이 얼마나 느린가 |
| `DEATH.expLossRatio` | 죽음이 얼마나 아픈가 |
| `AUTO.defaultPotionAt` | 자동 사냥이 몇 %에서 물약을 마시는가 |

몬스터의 체력·경험치·전리품은 `src/rpg/content/monsters.ts` 에, 아이템 값은 `items.ts` 에 있습니다.

## 같이 들어 있는 다른 게임 — AGI 경주

▶ **[플레이하기](https://tepalmafia.github.io/my-web-game/agi-race.html)** · 코드는 `src/` 바로 아래에 있습니다.

데이터센터를 짓고 GPU와 전력을 확보해, 경쟁 연구소 세 곳보다 먼저 AGI에 도달하면 이기는
경영 시뮬레이션입니다. 한 판 25분. 영어/한국어를 지원합니다.

- **투자를 받으면 지분이 줄어듭니다.** 일곱 번쯤 받으면 더 내줄 지분이 없습니다.
- **GPU는 전력이 있어야 돕니다.** 전력 계약을 잊고 GPU만 사면 산 만큼 그대로 놀립니다.
- **안전 검증을 건너뛰면 빨라집니다.** 대신 사고가 나면 그 자리에서 패배합니다.
- **진행도 45%를 넘으면 모델이 스스로 연구를 돕기 시작하고**, 그때부터 질문이
  "무엇을 살까"에서 "가속 ↔ 정렬 중 어디에 쓸까"로 바뀝니다.

이쪽 숫자는 `src/balance.ts`, 규칙은 `src/constraints/` 와 `src/state/` 에 있습니다.

## 직접 돌려보기

```bash
npm install
npm run dev        # 개발 서버 — / 는 RPG, /agi-race.html 은 AGI 경주
npm test           # 테스트 190개
npm run check      # 타입검사 + 테스트
npm run build      # 타입검사 + 두 게임 모두 빌드
```

`main` 에 푸시하면 GitHub Actions 가 빌드해서 GitHub Pages 에 자동 배포합니다.
