# 아덴의 그림자 — 세 가지 인정 (개정 4판)

> 3판에서 바뀐 것: 갈 곳이 광산뿐이었다.
> 숲과 강에도 깊이를 주고, 던전을 넣는다.

---

## 0. 왜 셋인가

혼자 하는 게임이라 남이 인정해줄 수 없다. 그 자리를 셋이 나눠 맡는다.

| | 무엇이 인정하는가 | 역할 |
|---|---|---|
| ① 세계가 인정한다 | 도달 불가능해 보이던 곳에 도달 | 목적지 |
| ② 기록이 인정한다 | 내가 세운 최고 기록 | 넘어야 할 것 |
| ③ 세계가 변한다 | 내가 한 일이 세계에 남음 | 가는 길 |

**③이 길을 열고, ①이 도달점이고, ②가 그 도달을 기록한다.**

---

# 1. 세계의 모양 — 세 갈래와 던전

## 1.1 깊이는 광산의 것이 아니다

지역을 가로로 늘리지 않는다. **있는 지역이 안으로 깊어진다.**
방향이 다를 뿐이다 — 광산은 아래로, 숲은 안으로, 강은 위로.

```
실버우드 마을
 ├ 초록 숲   →  깊은 숲    →  고목의 자리
 ├ 강가      →  상류       →  물이 시작되는 곳
 └ 광산 1층  →  2층  →  3층  →  최심부
```

각 갈래 끝에 그곳에서만 나는 것이 있다.

| 갈래 | 무엇이 나나 | 무엇으로 뚫나 |
|---|---|---|
| 숲 | 고목, 오래된 씨앗 | 벌목 |
| 강 | 깊은 물의 것 | 낚시 |
| 광산 | 최심부의 쇠 | 채광 |

## 1.2 한 캐릭터가 셋을 다 못 간다

총합 상한(200) 때문이다.

- 채광에 몰면 광산 깊이 간다
- 벌목에 몰면 숲 안쪽에 간다
- 낚시에 몰면 강 상류에 간다

**한 캐릭터가 한두 갈래만 끝까지 간다.** 나머지는 다음 캐릭터 몫이다.

## 1.3 마지막 물건은 셋이 다 필요하다

최종 물건은 세 갈래 끝의 재료가 모두 있어야 만든다.
**한 캐릭터로는 못 만든다.**

마을은 캐릭터가 바뀌어도 남는다(②). 그래서 **여러 캐릭터에 걸쳐 모은다.**

```
첫 캐릭터   채광에 몰아 최심부의 쇠를 가져온다
둘째        벌목에 몰아 고목을 가져온다
셋째        낚시에 몰아 깊은 물의 것을 가져온다
그리고 만든다
```

**"끝이 끝이 아니다" 가 문장이 아니라 구조가 된다.**

## 1.4 던전 — 캐는 곳이 아니라 뚫는 곳

세 갈래는 자원을 얻는 곳이다. **던전은 다르다.**

| | 세 갈래 | 던전 |
|---|---|---|
| 무엇을 하나 | 캔다 | 뚫는다 |
| 지형 | 늘 같은 자리 | **들어갈 때마다 다르다** |
| 왜 가나 | 재료가 필요해서 | 거기서만 나오는 것 |
| 끝 | 가장 깊은 곳 | 마지막 방 |

씨앗 기반이라 **매번 다른 던전이 공짜로 나온다.**
지형을 저장하지 않는 이 게임의 구조가 여기서 값을 한다.

### 던전이 하는 일

1. **되풀이할 수 있는 도전.** 세 갈래는 한 번 뚫으면 끝이지만 던전은 계속 간다
2. **다른 종류의 위험.** 캐다 죽는 것과 갇혀서 죽는 것은 다르다
3. **얻는 것이 다르다.** 재료가 아니라 물건이 나온다. 만들 수 없는 것들
4. **짐과 시간이 가장 비싼 곳.** 안으로 갈수록 돌아오는 길이 길다

### 던전의 규칙

- **입구는 밖에 있다.** 숲 어딘가, 광산 어딘가. 다닐 때 만난다
- **들어가면 나올 때까지 마을에 못 간다.** 중간에 접으려면 왔던 길을 되짚는다
- **깊이를 고른다.** 얕게 들어가 안전하게 나올까, 깊이 들어가 더 볼까
- **잃으면 크다.** 던전 안에서 죽으면 시체가 그 던전에 있는데, **그 던전은 다시 안 생긴다**

**마지막이 핵심이다.** 세 갈래에서 죽으면 되찾으러 갈 수 있다.
던전에서 죽으면 못 찾는다. 지형이 사라지기 때문이다.

그래서 던전에 들어갈 때 **무엇을 지고 들어갈지가 진짜 판단**이 된다.

### 세 조건

| | |
|---|---|
| 선택 | 얼마나 깊이 들어갈까. 무엇을 지고 들어갈까 |
| 불확실 | 다음 방에 무엇이 있는지 모른다. 지형이 매번 다르다 |
| 비가역 | 죽으면 그 던전째로 잃는다 |

# 2. ① 세계가 인정한다

## 2.1 도달은 네 종류다

"어디에 갔나" 만이 아니다.

| 종류 | 예 |
|---|---|
| **장소** | 광산 최심부, 고목의 자리, 물이 시작되는 곳, 던전 마지막 방 |
| **물건** | 우수한 구리 장검, 발도르의 물건, 던전에서만 나오는 것 |
| **실력** | 채광 100, 대장 100 |
| **행위** | 실패 없이 열 번 벼림, 맨몸으로 거미를 잡음, 던전을 한 번에 뚫음 |

## 2.2 세계가 반응하는 방법이 여럿이다

| 방법 | 무엇 |
|---|---|
| **칭호** | 이름 옆에 붙는다 |
| **NPC의 말** | 두린이 알아본다. 도달한 만큼만 열린다 |
| **지도** | 그 자리가 지도에 남는다 |
| **모습** | 칭호에 따라 캐릭터 그림이 조금 달라진다 |
| **마을** | 큰 도달은 마을 전체가 안다 |

## 2.3 칭호는 하나만 단다

여럿 얻어도 **하나를 고른다.**

- 고른 칭호가 이름 옆에 붙는다
- NPC가 그 칭호로 부른다
- 어떤 문은 특정 칭호가 있어야 열린다

**그러면 칭호가 장식이 아니라 선택이 된다.**

# 3. ③ 세계가 변한다

## 3.1 변화는 세 겹이다

| 겹 | 무엇이 변하나 |
|---|---|
| **땅** | 광맥, 길, 몬스터 분포 |
| **사람** | 마을 사람, 그들의 말과 하는 일 |
| **값** | 물건 시세 |

## 3.2 땅이 변한다

| 무엇을 하면 | 무엇이 남나 |
|---|---|
| 광맥을 다 캠 | 그 자리가 마른다. 다시 차오르는 데 오래 걸린다 |
| 나무를 다 벰 | 같다 |
| 같은 길을 여러 번 지남 | 길이 다져진다. 조금 빨라진다 |
| 몬스터를 많이 잡음 | 그 구역이 조용해진다 |
| **한 구역을 오래 비움** | **몬스터가 늘고 자원이 차오른다** |
| 물건을 놓고 감 | 그 자리에 남는다 (이미 있다) |
| 죽음 | 시체가 남는다 (이미 있다) |
| 층을 뚫음 | 그 길이 열린 채로 남는다 |
| **던전을 뚫음** | **그 던전은 사라진다. 입구만 흔적으로 남는다** |

**비운 곳이 도로 위험해지는 것이 핵심이다.**
안 그러면 세계가 한 방향으로만 안전해지고, 결국 아무 데도 안 위험해진다.

## 3.3 사람이 변한다

| 무엇을 하면 | 누가 어떻게 |
|---|---|
| 쇠를 많이 팜 | 대장간이 커진다 (이미 있다) |
| 나무·약초·물고기를 팜 | 빈 터에 사람이 들어선다 |
| 특정 물건을 계속 만듦 | 두린이 그걸로 나를 부른다 |
| 도달함 | NPC의 말이 열린다 |
| 한 NPC와 오래 거래함 | 값을 깎아주거나 먼저 물건을 내준다 |
| **던전에서 무언가를 가져옴** | **아무도 모르던 것이라 마을이 술렁인다** |

## 3.4 값이 변한다

**내가 시장을 움직인다.**

- 철 주괴를 백 개 팔면 값이 내려간다
- 한동안 안 팔면 도로 오른다
- 아무도 안 캐는 것은 비싸다

혼자 하는 게임이라 시장이 나 하나로 움직인다.
**그것이 오히려 감각을 준다** — 내가 이 마을의 유일한 공급자다.

## 3.5 지도가 셋을 잇는다

씨앗 고정 세계라 같은 자리가 계속 그 자리다. **내 흔적이 쌓인다.**

지도를 열면 다닌 길, 마른 자리, 안 간 곳이 보인다.
**빈 곳이 곧 다음 도달지다** — ①과 붙는다.

던전은 지도에 **입구만** 남는다. 안은 매번 다르니 그릴 수 없다.

# 4. ② 기록이 인정한다

## 4.1 기록은 세 층이다

| 층 | 무엇 |
|---|---|
| **물건에 새겨진 것** | 이 검이 무엇을 했나 |
| **마을에 남는 것** | 이 세계의 최고 기록 |
| **다음 캐릭터가 받는 것** | 넘을 것, 그리고 물려받는 것 |

## 4.2 물건에 이력이 새겨진다

```
철검 — 대장기술 62에 벼림 · 날카롭게
       늑대 47 · 거미 12 · 수리 3회
       광산 2층에서 부러짐
```

**부서질 때 그 기록이 남는다.**

## 4.3 마을에 기록이 남는다

**캐릭터가 바뀌어도 남는다.**

| 무엇 | |
|---|---|
| 가장 좋은 물건 | 만든 이의 이름과 함께 |
| 가장 깊이 간 곳 | 갈래마다 |
| 가장 오래 버틴 검 | 몇 마리를 잡았나 |
| 던전 최고 기록 | 몇 번째 방까지 |
| 얻은 칭호 | 전부 |
| **가장 크게 잃은 것** | 자랑이 아니라 흉터다 |

## 4.4 다음 캐릭터가 물려받는다

| 무엇 | 어떻게 |
|---|---|
| 칭호 | 앞 캐릭터가 얻은 것을 볼 수 있다. 다시 얻어야 쓴다 |
| 마을 | **앞 캐릭터가 키운 것은 남는다** |
| **세 갈래 재료** | **앞 캐릭터가 가져온 것은 마을에 남는다** |
| 물건 하나 | 앞 캐릭터의 유품 하나를 들고 시작한다 |
| 기록 | 넘어야 할 숫자 |

**세 갈래 재료가 남는 것이 1.3의 전제다.**

## 4.5 그래서 끝이 끝이 아니다

한 갈래의 끝은 한 캐릭터의 끝이다. **세계의 끝이 아니다.**
세 갈래를 다 모아야 마지막 물건이 나오고, 그건 여러 캐릭터의 일이다.

**세계는 계속 두꺼워진다.**

# 5. 셋이 맞물리는 그림

```
③ 땅이 변한다        →  마른 자리, 차오른 자리, 다져진 길
   지도가 채워진다    →  빈 곳이 보인다
① 빈 곳에 도달       →  칭호가 붙고 세계가 반응한다
③ 사람이 변한다      →  마을이 커지고 값이 움직인다
① 갈래 끝에 도달     →  그 갈래의 재료를 가져온다
② 마을에 남는다      →  다음 캐릭터가 이어서 다른 갈래를
①  세 갈래가 다 모임 →  마지막 물건
② 기록에 남는다      →  다음 세계가 넘을 것

던전은 그 사이 어디서나 → 되풀이할 수 있는 도전
```

# 6. 세 조건 대조

| | 선택 | 불확실 | 비가역 |
|---|---|---|---|
| ① 갈래 | 어느 갈래를 끝까지 갈까 | 거기 뭐가 있는지 모른다 | 예산을 쓰면 못 무른다 |
| ① 칭호 | 어느 칭호를 달까 | 어떤 문이 열릴지 모른다 | — |
| **던전** | **얼마나 깊이. 무엇을 지고** | **매번 다르다** | **죽으면 던전째로 잃는다** |
| ② 기록 | 안전하게 만들까 기록을 노릴까 | 우수품이 나올지 모른다 | 실패하면 재료가 사라진다 |
| ③ 땅 | 어디서 캘까 | 얼마나 남았는지 모른다 | 다 캔 자리는 안 돌아온다 |
| ③ 값 | 지금 팔까 쟁여둘까 | 값이 어떻게 움직일지 모른다 | 판 것은 안 돌아온다 |

# 7. 순서

전체설계 10절에 이렇게 얹는다.

| 단계 | 무엇을 함께 |
|---|---|
| **C (광산 층)** | ① 장소 도달 · 칭호 · NPC 반응 |
| **C** | ③ 층을 뚫으면 길이 남는다 |
| **C 뒤** | ③ 땅의 변화 + 지도 |
| **D (하루)** | ③ "오래 비움" 이 성립한다 |
| **E (축)** | **숲·강에 깊이를 준다** · ③ 사람·값의 변화 |
| **E 뒤** | **던전** |
| **F** | ② 기록 전부 · 캐릭터 이어하기 · 마지막 물건 |

**숲·강의 깊이를 E에 두는 이유:**
벌목·낚시가 있어야 그 갈래를 뚫을 수단이 생긴다.

**던전을 E 뒤에 두는 이유:**
세 갈래가 다 있어야 던전이 "또 다른 종류" 가 된다.
지금 넣으면 그냥 광산 하나 더다.

# 8. 아직 안 정한 것

- 칭호를 몇 개, 무엇으로 둘 것인가
- 갈래마다 깊이가 몇 겹인가
- 던전이 몇 층이고 무엇이 나오는가
- 던전 입구가 어떻게 생기고 몇 개인가
- 광맥이 마르고 차오르는 시간
- 값이 얼마나 움직이는가
- 마지막 물건이 무엇인가
