# 아덴의 그림자 — 타격감 사운드 설계

WebAudio 합성 전용. 오디오 파일 0개. 모바일(390×844) 우선.

## 0. 전제
타격감은 소리만으로 나오지 않는다. 히트스톱(순간 정지), 타이밍 정렬, 화면 흔들림이 함께 있어야 한다.

## 1. 아키텍처
core/ 는 오디오를 전혀 모른다. feedback 이벤트만 내보낸다.
audio/ 가 그 이벤트를 구독한다. 방향은 항상 audio → core.
core/ 가 audio/ 를 import 하면 헤드리스 봇이 죽는다.

audio/
  bus.ts    AudioContext, 마스터 게인, 컴프레서, 보이스 제한, 음소거
  synth.ts  합성 기본 단위
  sfx.ts    각 소리의 정의표 (숫자만, 계산 없음)
  index.ts  feedback 이벤트 → sfx 매핑

audio/ 는 통째로 꺼도 게임이 돌아가야 한다.

## 2. 모바일 제약 (가장 실수하기 쉬운 곳)
- 폰 스피커는 약 200Hz 아래를 재생하지 못한다. 무게를 60Hz 서브에 걸면 폰에서 사라진다
- 무게는 150~400Hz 가 진다. 서브(60~90Hz)는 이어폰 보너스로만 취급
- iOS 는 사용자 제스처 이후에만 AudioContext 가 살아난다. 첫 터치에서 ctx.resume()
- 게인 엔벨로프는 exponentialRampToValueAtTime, 0 대신 0.0001. 선형 램프는 딸깍거린다
- 스케줄링에 setTimeout 금지. ctx.currentTime + offset 으로 예약

## 3. 합성 기본 단위 (synth.ts)
noise({ hp?, lp?, bp?, q?, dur, gain, at? })  화이트노이즈 → 필터 → 엔벨로프
thump({ from, to, wave, dur, gain })          주파수를 from→to 지수 하강. "부딪혔다"의 정체
metal({ base, ratios, dur, gain })            비조화 배음비 [1, 2.41, 3.83]. 금속·종
sweep({ from, to, q, dur, gain })             밴드패스 중심주파수 이동

공통: 어택 2~5ms, 감쇄는 지수. 어택 10ms 초과 시 물렁해진다.

## 4. 소리 사양 (dur=ms, g=상대게인 0~1, 모든 소리 피치 랜덤 ±6%)

### 4.1 검 타격 (일반) — 3층을 같은 시각에 시작할 것
A 딸깍: noise hp2000Hz dur15 g0.5     (어택. 타격감의 절반)
B 무게: thump 240→95Hz triangle dur70 g0.8  (폰에서도 들리는 무게)
C 질감: noise bp850Hz Q2 dur45 g0.35
층을 어긋나게 하면 두 번 때린 것처럼 들린다.

### 4.2 검 타격 (크리티컬) — 크기가 아니라 종류가 달라야 한다
일반 3층 + 아래 추가:
서브: thump 90→38Hz sine dur200 g0.9 (이어폰 전용)
잔향: metal base3000Hz dur300 g0.25, +25ms 지연
덕킹: 다른 모든 소리를 80ms 간 -6dB
볼륨만 키우지 말 것. 저역이 더 낮고, 꼬리가 길고, 주변이 조용해진다.

### 4.3 막힘 / 방어 성공
A: noise hp3000Hz dur8 g0.6
B: metal base1400Hz ratios[1,2.41,3.83] dur220 g0.5
무게 층(thump)을 넣지 않는다. 막았으니 몸에 안 들어갔다는 뜻이어야 한다.

### 4.4 빗나감
A: sweep 1600→450Hz Q3 dur130 g0.3
저역 금지. miss 에 무게가 없어야 hit 의 무게가 대비로 살아난다.

### 4.5 피격 (플레이어가 맞음)
A: thump 160→55Hz sine dur160 g0.9
B: noise lp1200Hz dur90 g0.4
덕킹: 마스터 -4dB 를 80ms 유지 후 복귀
고역을 깎아 둔탁하게. 덕킹이 숨 막히는 느낌을 만든다.

### 4.6 채굴 — 수천 번 반복된다. 피로 방지가 전부
A: noise bp2200Hz Q4 dur25 g0.4
B: thump 300→140Hz square dur55 g0.5
변형 4종 순환 + 피치 랜덤 ±8%. 전체 200ms 이내.
광석 획득 순간만 다른 소리: metal 350→700Hz 상승. 보상 신호.

### 4.7 제작 실패 — 볼륨이 아니라 정적으로 만든다
0ms    모든 소리 즉시 정지 (마스터 게인 0.0001)
60ms   thump 95→28Hz sine dur500 g1.0 + noise lp400Hz dur200 g0.3
560ms  아무것도 없음. 마스터 복귀는 800ms 후
앞뒤의 침묵이 큰 소리보다 강하다. 가장 공들일 소리.

### 4.8 우수품 제작 성공
A: metal base 800→1600Hz 상승 dur400 g0.6
B: thump 200→300Hz 상승 sine dur250 g0.4
실패가 하강이면 성공은 상승. 방향만으로 의미가 전달된다.

## 5. 버스 요구사항
- 동시 발음 8개 제한. 초과 시 가장 오래된 것 회수
- 같은 소리 12ms 내 중복 금지 (연타 시 게인 폭발 방지)
- 마스터 컴프레서 DynamicsCompressorNode threshold -12dB ratio 4
- 음소거 토글 + 볼륨 슬라이더, localStorage 저장
- 탭 백그라운드 시 ctx.suspend()

## 6. 히트스톱 — 소리와 같은 프레임에 시작할 것
일반 타격: 정지 30ms, 흔들림 2px 60ms
크리티컬: 정지 60ms, 흔들림 5px 120ms
플레이어 피격: 정지 45ms, 흔들림 4px 100ms
장비 파괴: 정지 120ms, 흔들림 없음 (정적이 연출)
한 프레임만 어긋나도 타격감이 무너진다.

## 7. 검증
- 모바일 실기 확인 필수. 데스크톱에서 좋던 저역이 폰에서 사라지는 일이 흔하다
- 자동 채집 3분 실행 시 소리 뭉개짐 없는지 (보이스 제한 확인)
- audio/ 비활성화 시 게임과 봇이 정상 동작 (테스트로 고정)
- 타격 100회 연속 클리핑 없음
